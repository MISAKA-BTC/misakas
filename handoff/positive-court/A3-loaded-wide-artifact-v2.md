# A3 same-descriptor wide artifact startup — V2

Source-only concrete Loaded owner with six UNRUN tests. Cargo/rustc remain HOLD under A0 shared scheduling. This adds a generic regular-file startup component and borrowed CPU/session/Open bridges. It does not activate a native/SDK backend or establish a complete multi-process claim/Court/recovery path.

`load_wide_artifact_v2` accepts the caller-open regular `File` itself plus independently admitted expected binding, opaque verified V2 binding, original context and retained external ticket. Those pins' original association, external inventory and exclusion of concurrent file/descriptor-offset mutation remain explicit caller preconditions. It never derives trusted expected pins from the candidate file, reopens a path, changes a layout/context/tokenizer or interprets a ticket as native authority.

The constructor first checks Core's private audited Source profile through a new nonallocating `require_source_program_local_profile_v1`. The existing scanner still independently checks that gate on every attempt. Unknown builds refuse before file/backend work. This is trusted local build metadata, not installed-source or compiler authentication.

Each accepted attempt ALWAYS claims the entire configured finite `max_new_owner_bytes` allowance against cumulative retained claims and the full operation cap before the host callback or backend. If an existing host reserver is supplied, one actual allowance lease is acquired before metadata/header work and retained after all newly owned data. If no reserver exists, logical admission still applies and no host guard is fabricated. Callback bookkeeping and independent external owners require their stated external reservation. The separate compile helper remains quote/opaque-owner data: it does not itself enforce or create a host lease.

The owner moves in this same File, bounded header, canonical/NF Source owner, private freshly compiled plan, native Params, original pins, data root, stage quote and optional lease. Local checked-header/plan borrows end before these owned fields move; there is no self-reference or unsafe lifetime extension. It has no Clone, mutable/owned extraction or public raw-plan getter. The plan's interior-mutable fusion cache cannot be reached externally. All data fields precede the guard in drop order; new heap locals also drop before the guard on failed startup.

The exact stage order is configured header admission/read, Source scan/consuming decode, split original-byte/table validation, producer-prequoted unchanged compilation, and native owned parameter load plus authoritative G14 root check. Every stage checks named co-live header/Source/compile/Params/root terms against the whole allowance and original operation maximum; sub-operation maxima are never raised. Independent external fields on sub-limits must start at zero; this aggregate supplies those actual co-live sums. Prior Params retained claims are subtracted only from the duplicated prior-allowance term, so nested admission counts previous data exactly once at that join. Conservative component inline roots and sequential scratch are still deliberately overcounted.

The artifact-side configured header helper is pure checked arithmetic with fixed errors. It surrounds even initial backend failures with frame/native ceilings, the parser's existing declared8192-byte scratch allowance, actual error enum root and a finite static Header/Table/Program literal String census. It is limited to audited-profile native File and immutable same-Source-byte validation. Native File errors are inline OS/static EOF errors; no arbitrary provider error or `to_string` is admitted. Borsh comparison/count mismatch cannot arise from that unchanged canonical Source owner. The helper adds no Core dependency or alternate parser/layout grammar.

Attempts, header/payload read allowances, parser currency, Source scanner steps, quote visits, Params metadata/data work and retained claims are cumulative and never reset/refund. Failed later stages retain accepted earlier charges; refused next admission is atomic. These are logical allocation/symbolic-work limits, not all NF/compiler CPU, elapsed time, physical RSS, allocator internals, OOM recovery or bounded OS IO scheduling.

Pre/post dev/ino/length/mtime/ctime checks use the retained descriptor and are supplemental consistency checks, not an atomic immutable snapshot. Actual newly owned native parameter values must still match the independently expected G14 root. Once loaded they cannot be changed by later file writes. Data identity gives no model qualification, computation verdict, Gate C, certification or credit.

`prepared_cell` requires the caller's Wide external inventory to cover the entire prepaid Loaded allowance plus original external/prior claims BEFORE calling the existing Prepared constructor/context hashing. `resident_open` derives its retained declaration from that same floor and borrows the actual private plan/native values/raw original program. Workspace, transport/deadline adapters and exports retain separate reservations. Direct low-level CPU calls do not enforce session counters; public `serve` calls the existing mandatory cumulative session. Its fixed `LoadedWideServeErrorV2` copies all terminal accepted `WideCellUsageV2` before dropping owned diagnostics. Only pre-session admission errors receive explicitly zero session usage. Failure charges remain available for journaling/retry accounting.

Six UNRUN regressions cover a real small regular file through Source/compile/native Params and ordinary CPU i64 MIN/MAX, guard lifetime through borrowed prepared operations, original tokenizer18/job0 and undeclared layout, each stage's failure/no-refund/release, bad-root retries/attempt ceiling, truncation before payload, bridge floor and duplicate-Hello terminal usage equality with upstream. Expected native endpoint bytes/root are fixed before candidate file creation. The synthetic original max context16 is preserved. Unsupported-build tests label refusal and do not claim successful startup/CPU execution.
