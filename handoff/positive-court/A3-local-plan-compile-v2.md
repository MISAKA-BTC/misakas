# A3 local plan compilation — V2

Source-only producer quote and opaque compiler owner. Three new tests are UNRUN. Cargo/rustc remain HOLD under A0 scheduling; syntax/applicability and independent source reviews are not type-check or runtime results.

The existing `TirPlan::compile` body is unchanged. New cfg(node) APIs at `misaka_palw_tir_exec::plan` accept only an immutable `LocalSourceProgramOwnerV1` from Core74bd, whose private constructor already enforces supported build, canonical same-byte decode and NF validation. No caller-created program, numeric quote, decoder callback, support boolean or mutable compiled plan substitutes for that provenance.

`tir_plan_compile_quote_visits_upper_v2` is pure O(1), so a cumulative startup budget may precharge the allocation-free quote walk before `prepare_tir_plan_compile_v2`. Prepared borrows the exact Source owner and private quote; its consuming `compile()` calls the unchanged compiler exactly once. Backend diagnostic payloads are dropped locally before returning fixed error kinds. The caller must admit the complete logical peak and retain any host guard required by its configured policy before that consuming call. The helper does not enforce that caller obligation: its quote and returned owner are logical data and fabricate no guard. The Loaded aggregate supplies mandatory logical admission and an optional existing host reservation; None does not mean a host guard exists.

`LocalCompiledTirPlanV2` owns a private fresh plan and quote with no retained Source borrow, Clone, Deref, public raw-plan getter or unchecked conversion. This permits the startup aggregate to own Source and compiled result without self-reference. The raw plan getter is crate-only: a shared public TirPlan could initialize its public fused OnceLock and allocate/inject fusion payloads outside this contract. Later legitimate execution, refinement, fusion and exports require their own admitted stages.

The named conservative formula is `operation = original Source + retained compiler owner + scratch + caller external`. Scratch sums one SECOND complete admitted Source envelope for compile's unchanged second `validate` pass, duplicate occurrences used by slot-base construction, maximum whole-constant Gather i128 slab plus usize shape, one state-touch tree, row-site temporaries and actual Prepared/Result framing. The reused Source envelope overbounds known validation allocations, including parse/diagnostic terms not needed by validate-only. It neither skips the second validator nor exposes/copies private NF pricing. Original Source remains separately retained, and compiler-owned ProgramInfo is explicitly retained as well.

Retained requests enumerate the full original program clone, ProgramInfo blocks/carry shapes, native constant Bufs, BlockPlans/NodePlans and every input type/rank/interval, occurrences/slot bases, all declaration state/layer slots and typed state shapes, parameter memberships, row-site gathers/groups/dense flags and each group's member Vec minimum. Scratch includes the actual temporary view, carried tree and its pinned std input Vec, by-index map and temporary types/dimensions. All growth/tree policies use reviewed public typed envelopes; no encoded-byte multiplier or guessed scratch constant hides allocations. The carried set has at most canonical MAX_CARRY8; official Rust1.93 uses an input Vec followed by insertion sort for that size, with no sort heap. The input Vec still overlaps the tree and is charged.

Four positive limits bound quote visits, retained requests, scratch requests and operation requests, with checked arithmetic and static errors. The quote walk is bounded by eight named linear metadata families; it does not traverse element payloads. Additional occurrence-reference, constant-interval and whole-slab lane counters are explicit partial dimensions. They do not claim all validation/compiler CPU, instructions, elapsed time, fees, RSS, allocator internals, OOM recovery or model work. The original source/header/file/class/context/previous exports retain their separately stated reservations.

Three UNRUN cases cover actual metadata compilation of narrow/wide canonical programs, repeated layers and state instances, transpose/row groups, native constant buffers and whole constant slab, exact/four one-below limits, and checked growth/tree overflow. Unsupported Source profiles print an explicit refusal label and do not claim compilation success. No model arithmetic executes in these tests.

Main and a separate independent reviewer compared every reachable allocation against compile/plan_block, tiers, ranges, element buffers, immutable Source provenance and official pinned std collection paths. No concrete blocker remained within this logical allocation/partial-work scope. Whole Loaded artifact ownership and generic process/SDK integration remain separate work. No native flags, defaults, wire IDs, model tiers, qualification or credit rules change.
