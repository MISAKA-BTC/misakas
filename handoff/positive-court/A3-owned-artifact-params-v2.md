# A3 fully owned artifact parameters — V2

Source-only opt-in Node component. All four new tests are UNRUN; Cargo/rustc remain HOLD under A0 scheduling. This completes a resident-parameter loading component from independently admitted inputs, not generic startup, model process registration or a complete claim/Court path.

## Inputs and data identity

`OwnedParamInputsV2` borrows a bounded checked PALWTIR1 header, canonical normal-form program, unmodified `TirPlan::compile` result, independently admitted expected binding, opaque verified V2 binding and original context. These owners and their existing reservations remain external. Their original association, same opened descriptor, source stamp/mutation checks and bounded provider internals are caller preconditions. Literal consistency checks do not authenticate arbitrary mutated compiled fields, recompute unquoted context hashes or construct another StepSpace.

The header's program and registration tokenizer match the expected class. Its optional layout, when declared, matches every original scalar/word. Empty layout stays undeclared and uses only the admitted expected layout, labelled `IndependentlyExpectedOnly`; no default layout, maximum-context rewrite or new file encoding is invented. Registration tokenizer18 and actual job tokenizer0 remain distinct in the fixtures.

`load_owned_artifact_params_v2` reads checked extents from that already-open `Read+Seek` owner. Every I8/I16/I32/I64/Idx instance becomes its own exact native Vec through one bounded byte chunk and `from_le_bytes`. I128 parameters refuse. No unsafe, mmap, lazy whole-row materialization, Tensor or full i128 parameter mirror is introduced. Insertion moves each Buf into an empty preallocated Params slot without cloning payloads.

The authoritative Core inventory visitor enumerates original G14 coordinates. One reused piece chunk re-encodes the newly OWNED native slices into `artifact_leaf_parts_v1` and the existing promotion frontier. Their root must equal the independently expected artifact root. Immutable owned values then no longer depend on later source-file changes. This authenticates data identity; it grants no model qualification, computation verdict, Court result, Gate C or credit.

## Named logical requests and lifetime

Producer-side `quote_owned_params_table_v2` follows exactly `TirParams::new`: Params root, outer table, every global/per-layer Option<ParamData> slot including unread layers, per-layer flags, outer ranges and every OnceLock range slot. It uses the reviewed shared public Vec capacity envelope, exact typed arrays where the producer requests exact arrays, and no row-source heap. Payloads are a separate exact sum.

Core visitor scratch uses exact readers Vec<BTreeSet<u8>>, actual Param-reference memberships times the public typed BTree envelope, outer instance vectors and per-layer instance slots. Its count and visit projections are sequential, so one peak scratch envelope covers them while both walks receive work admission. Prequote leaf counts only admit resources; actual enumeration remains the existing authoritative visitor. Tensor bytes must fit Core u32 offsets. Frontier peak slots use the actual admitted leaf depth; no dense hash tree is made. Chunk size is the largest actual piece or element width, not an unconditional32KiB floor. Named hash/header objects use their real Rust types; no unexplained scratch constant stands for unknown heap.

Retained new owner is `sizeof(owner)+Params heap+total native payload`. The current tensor is already in total payload, not added again. New-owner peak additionally covers one chunk, visitor metadata, frontier and named hash objects. `max_operation_bytes` adds the caller's external reservation and previously accepted retained claims. These are logical allocation requests, not allocator RSS, arbitrary compiler stack frames or OOM recovery guarantees. The BTree policy currently supports64-bit targets; unsupported widths refuse.

A persistent `OwnedParamBudgetV2` precharges each accepted attempt before nested metadata walks, then accepted read bytes, leaves, work and retained claims before guard/parameter allocation/read. Checked atomic admission cannot reset/refund counters after guard, IO, identity or root failures. Symbolic work counts metadata visits, bytes, native elements and hash bytes; it is not elapsed time, CPU instructions, fees or model work.

`OwnedArtifactParamsV2` retains the optional existing Node memory lease after its native Params field, so params drop before the guard. The guard covers the new-owner peak and remains attached conservatively after scratch is freed. No global flag is changed and no guard is fabricated if no reserver is supplied. The owner has no Clone or move-out getter. Shared Params exports still support deep Clone; arbitrary copies require the caller's separate reservation/external inventory, and this guard does not follow them. The getter returns `&TirParams<'_>` tied to the owner.
