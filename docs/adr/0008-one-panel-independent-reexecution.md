# ADR-0008 — G14の1席Panel・独立完全再実行を選ぶ理由

- 文書日付：2026-11-26（Asia/Tokyo）
- 文書区分：**DECISION_RATIONALE**。判断の背景・理由・代替案・帰結を記す。
- 対応仕様：[RFC-0008](../rfc/0008-g14-panel-and-verification.md)。数式、形式、状態遷移、受入条件と提案部分の区分はRFCを正本とする。
- 進捗・実装完了・公開有効化を示す文書ではない。新たな採否は明示的な決定を必要とする。

## 背景

検証者数を増やすほど通常の完全再実行費用と運用準備が増える。一方で、肯定票を多数集めるだけでは有効な計算反証を打ち消せない。

## 決定

G14の標準Panelはproducerから独立した一席の完全再実行を中心とし、他の公開検証者による単独反証を閉じない。選出、役務、承認、資料case、Finalとの結合はRFCへ置く。

## 判断理由

- 通常の再実行費用を抑えつつ、客観的反証を多数決に従属させないため。
- 選出席、実際に監視する参加者、独立operator、Node数を個別に評価するため。
- 元claimなしに局所Courtだけを作って採掘する経路を閉じるため。

## 比較した方針

Panelなしの成功、部分一致だけで全量義務を代替する方式、本人の別addressを独立検証者とみなす方式は採らない。多数の肯定署名を通常必須にする方式もG14の標準にはしない。

## 帰結

選出席が不正な場合も、正直な監視者が実際に資料を取り、再実行し、期限内に有効な反証を包含できることが必要になる。署名数は再実行の証拠にならない。

後発者が許可を待つ間に不正を見逃さないため、承認権と公開反証権を分ける。承認の意味と範囲を署名で固定することで虚偽承認者の個別責任を特定する。
