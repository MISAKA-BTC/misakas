# ADR-0009 — 有界Court・反証優先・検証先行Finalを選ぶ理由

- 文書日付：2026-11-26（Asia/Tokyo）
- 文書区分：**DECISION_RATIONALE**。判断の背景・理由・代替案・帰結を記す。
- 対応仕様：[RFC-0009](../rfc/0009-court-and-claim-final.md)。数式、形式、状態遷移、受入条件と提案部分の区分はRFCを正本とする。
- 進捗・実装完了・公開有効化を示す文書ではない。新たな採否は明示的な決定を必要とする。

## 背景

モデルを持たないNodeが、単なるRootの相違や投票数だけでどちらの計算が間違っているか判断することはできない。相手の協力を必須にすると、悪意ある参加者が反証を止められる。

## 決定

元claimとモデルへ認証された有界な局所関係をCourtで裁き、有効反証を肯定承認より優先する。資料不足、供給義務違反、local故障、未検証終了を分ける。時計、局所checker、Final述語、帰責、保持の仕様はRFCへ置く。

## 判断理由

- Nodeが必要な重みの一部だけを受け取り、その出所と演算を確認できるため。
- 対話に応じない相手にも、既に局所化された反証を提出できるため。
- ネットワーク不達や検閲を、そのままMinerの算術不正にしないため。
- 正常な短経路だけでなく、最遅の合法的異議まで受付時に資源化するため。

## 比較した方針

Rootが違う方を即有罪にする方式、任意質問への未応答だけのslash、再掲で期限を延ばす方式は採らない。局所化の対話は補助として残すが、直接反証の前提にはしない。

## 帰結

有界checkerのcoverage、資料供給、期限内包含、保護容量が必要である。これらが不足した場合の未検証終端も設計し、無告発を自動成功へ変換しない。新しいfiling clock等の未採択案は提案として分離する。
