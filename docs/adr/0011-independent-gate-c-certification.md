# ADR-0011 — G14と公開Courtに合意creditを結び付ける理由

2026-11-27 採択。対応仕様は[RFC-0011](../rfc/0011-gate-c-and-consensus-credit.md)。

## 背景

旧profileではG14 Panelの再実行に加え、別に抽選した検証者の肯定承認を要求した。抽選が成立しない場合には正しい仕事も認証待ちになり、同じ仕事の再実行・資料取得・署名の費用を追加で要した。

## 決定

新規profileでは独立Gate Cを廃止する。G14の選出1席が完全再実行を引き受け、選出外の参加者にも全claimの検査と公開Courtへの反証を開く。決定論的に成立した単独反証で虚偽承認を覆し、Minerと署名したPanelの責任を個別に裁定する。選出外の有効な立証者もCourtの発見報酬を受けられる。

## 判断理由

選出席がMinerと共謀しても、元資料に基づく客観的な違反が一件確認されればNodeは同じ裁定を再現できる。複数の肯定署名を集める費用を削減する一方、不正claimごとに監視者が実際に資料を検査し、元期限内に反証を届けられるという安全性の仮定を引き受ける。公開されているだけでは監視や包含を保証できない。

## 比較した方針

独立Gate Cは抽選stakeの正直割合と参加率に依存する。G14・公開Courtでは検査機会、資料取得、期限内包含に依存する。選出席の署名だけで即時決済する案では、共謀を公開反証で覆す機会を確保できない。

## 帰結

新規profileのfork choice、EXEC、決済、pruningが同じFinalの根拠を読む必要がある。監視資料とCourtの保護容量、供給違反時の停止を公開前に実証する。既受理claimと旧検証者の責任・報酬は受付時契約を守る。性能目標の達成は実測で判定する。
