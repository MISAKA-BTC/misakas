# ADR-0017 — モデル停止・解除・恒久廃止を選ぶ理由

- 文書日付：2026-11-26（Asia/Tokyo）
- 文書区分：**DECISION_RATIONALE**。判断の背景・理由・代替案・帰結を記す。
- 対応仕様：[RFC-0017](../rfc/0017-model-stop-and-retirement.md)。数式、形式、状態遷移、受入条件と提案部分の区分はRFCを正本とする。
- 進捗・実装完了・公開有効化を示す文書ではない。新たな採否は明示的な決定を必要とする。

## 背景

不適切なモデルを停止・廃止する制度が、そこに参加した正常なPanelまで一括処罰すると、不正を調べる動機を損なう。一方で兼任者の全資金を保護すると、採掘担保の逃避が可能になる。

## 決定

モデルへの可逆停止・恒久廃止と、個人の違反に対するCourt責任を分離する。用途別lotで検証資金を一括廃止から保護し、対象採掘資産の処分は限定scopeで行う。票、case、freeze、burn対象、終端と保存則はRFCに置く。

## 判断理由

- BFTに「正常なPanel」を個別判別させる追加制度を作らないため。
- MinerがPanelを兼任するだけで採掘担保を逃がせないようにするため。
- 廃止した方がBFT自身に大きな没収報酬が入る誘因を作らないため。
- 虚偽告発だけで報酬が発生する構成を避けるため。

## 比較した方針

全Panelのbondを一括burnする案、BFTへ没収資産を配る案、停止票を廃止票へ流用する案、別名再登録で停止を解除する案は採らない。個人不正は客観的Courtへ、モデル採否は限定BFTへ分ける。

## 帰結

正常な検証者の保護は用途上の保護であり、不正な検証者の個別slashを免除しない。BFT判断の質やSybil共謀の問題は残り、報酬率だけで経済安全性が証明されたとはしない。
