# ADR index

ADRs are **short decision records**: Context, Decision, Consequences, Links. The rules they decided
are stated in the **Spec** ([spec/](../spec/README.md); PALW in [spec/palw](../spec/palw/00-index.md)),
and the reasoning in **Design** ([design/](../design/README.md)). [INDEX.md](../INDEX.md) explains the
four document types. [INVENTORY.md](INVENTORY.md) records, file by file, where each ADR's content went
in the 2026-09-27 restructure. Use [templates/adr.md](../templates/adr.md) for a new ADR.

- **Numbers.** Take the next number from this file, not from `ls` (see "Number hygiene"). **The next
  number is 0156.**
- **Superseded ADRs** keep their bodies, with a banner at the top that names what superseded them.
- **Slimmed ADRs** say where their full text went (`design/palw/archive/`).
- **The sections this file used to carry** ("The direction that governs", "Activation axis", "What the
  current direction still owes", "What to build next", "Security amendments", "Still governing" and
  the long status table) are in [design/palw/archive/adr-index-2026-09-27.md](../design/palw/archive/adr-index-2026-09-27.md).
  Their living successors are [spec/palw/16](../spec/palw/16-network-parameters-and-fences.md) (what is
  armed where), [design/palw/lineage.md](../design/palw/lineage.md) (the direction) and
  [design/palw/principles.md](../design/palw/principles.md) (the order of work).
