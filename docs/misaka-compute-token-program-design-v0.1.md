# MISAKA Compute Token Program v0.1 — 不採用理由

Status: **Withdrawn / 不採用。**

VLT certificate に別通貨の emission と validator の投票重みを結び付ける Token Program は継続しない。PALW 自身が有用計算を consensus work として扱うため、別の compute 台帳・通貨・報酬 overlay を維持する必要がなくなった。旧台帳・emission 実装は削除済みであり、判断は [ADR-0126](adr/0126-the-validator-carve-drops-to-a-fifth-and-the-stake-reorg-gate-stays.md) と [ADR-0134](adr/0134-the-compute-overlays-committee-beacon-retires-at-a-height-and-its-machinery-goes.md) に従う。
