# 文書の責務と更新

[RFC-0001](../rfc/0001-principles-and-governance.md)に従い、20本のRFCへ実装設計、20本のADRへ判断理由を集約する。RFCとADRは同じ番号で対応させる。

数式・schema・状態遷移・拒否条件・期限・予算・移行・受入条件はRFCへ置く。背景・代替案の比較・理由・帰結はADRへ置く。安全性の仮定と保証限界は仕様の一部なのでRFCにも明記する。

旧RFC/ADR本文のarchive、草案の履歴コピー、v1/v2別体系を配布docsへ残さない。旧参照は小さな対応表で解決し、実測証拠は設計本文と区別する。文書再編で提案を採択・有効化へ昇格させない。
