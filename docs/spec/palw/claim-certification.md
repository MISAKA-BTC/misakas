# G14の成功Finalと合意credit

[RFC-0008](../../rfc/0008-g14-panel-and-verification.md)、[RFC-0009](../../rfc/0009-court-and-claim-final.md)、[RFC-0011](../../rfc/0011-gate-c-and-consensus-credit.md)が正本。

新規profileでは選出1席の完全再実行、選出外にも開かれた異議期間、資料義務とCourtの終端を選択枝で確認する。未解決case又は資料供給違反のあるclaimに成功効果を与えない。元profileのGate C署名・期限・責任は既受理claimに限って適用する。
