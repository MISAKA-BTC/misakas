# claim Finalと独立Gate C

[RFC-0008](../../rfc/0008-g14-panel-and-verification.md)、[RFC-0009](../../rfc/0009-court-and-claim-final.md)、[RFC-0011](../../rfc/0011-gate-c-and-consensus-credit.md)が正本。

G14 Panelの完全再実行承認、元の公開異議期間・資料条件、Courtを経てclaim Finalへ進む。独立Gate CのSecurityCertified、正規Ticket当選、受賞block受理、報酬決済は別の条件である。

未認証claimは合意credit・受賞・決済への成功効果を持たない。BFTモデル採用、局所Court一致、単なる未告発、ローカルreplayの一致は独立認証を代替しない。反証は肯定承認に優先する。

抽選位置数、必要承認数、復元抽出、適格bond、producer除外、独立operator数は対象profileのDrawPolicyへ固定する。過去fixtureの75位置/41承認を全profileの普遍的定数としない。
