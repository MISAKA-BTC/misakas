# 合意・DAG・認証の責任分界

[旧ADR-0180](../rfc/0001-principles-and-governance.md) は PALW のみの合意と BFT validator 不使用の採用理由を記録します。DNS退役・legacy reader・移行は [RFC-0012](../rfc/0015-dag-blocks-and-settlement.md) を参照します。

[RFC-0018](../rfc/0011-gate-c-and-consensus-credit.md) の `Final` と `SecurityCertified` を区別し、claim ごとの認証と固定のBFT validator集合を同一視しません。Rule Eは [旧ADR-0178](../rfc/0015-dag-blocks-and-settlement.md)、物理生成機会は [RFC-0016](../rfc/0012-bonds-budgets-and-slashing.md)、予算は [旧ADR-0176](../rfc/0012-bonds-budgets-and-slashing.md#8-claim予約の分解と期間上限)。

延期した画像・動画・改善が共通経路から開かないことと、残すテキスト・認証・会計の回帰は別途確認します。[延期方針](../governance/post-mainnet-scope.md) / [状態](../STATUS.md)。
