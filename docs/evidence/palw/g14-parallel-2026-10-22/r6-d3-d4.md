## D4 (user decision): post-Final duty clocks for text29 and funded v11 / Final27

New module `consensus/core/src/palw_native_post_final_duty_v1.rs` (child of `palw_state_v2`):
- Accusation: funded-execution action **47** `POST_FINAL_ACCUSE_ACTION_V1` (body `family ‖ job ‖ accusation[64]`, signer = accuser,
  Active, not the producer), `accuse_post_final_v1`. Accepted only while the fee is held inside H (`native_accusable_after_final_v1`).
  Records `PalwNativePostFinalDutyRowV1` in aux 144 under new prefix `0x02 ‖ family ‖ job` with one `CourtDutyClockV1` per responsible
  actor (text29/funded11: the held producer). RFC-0028 derivation: `predecessor = accepting block/DAA`, `first_eligible = DAA+1`,
  `response_deadline = DAA + turn_deadline_daa` (adopted per-turn deadline); refused if the deadline would not close before H.
- Answer: action **48** `POST_FINAL_ANSWER_ACTION_V1` (body `family ‖ job ‖ u32 len ‖ bytes ≤ 64 KiB`), signer must be the clock's
  answerer, `first_eligible ≤ now ≤ deadline`, once; records `(daa, digest)`.
- Supply: `observe_native_post_final_duties_v1` per block (wired next to the D3 sweep): an open, unanswered clock records the DAA as
  its supplied opportunity when the block's actual unreserved court spend (`court_cost_spent`) leaves room for one packet of the pinned
  `PALW_COURT_SERVICE_PROFILE_V1` (typed-missing → no-op).
- Decision: `decide_native_post_final_duty_v1` — latest turn; window open / answered → undecided; silent + supplied →
  `PartyDefault`; silent + unsupplied → `NoSlashHold`. `palw_native_post_final_default_fold_v1::decide_native_post_final_default_v1`
  routes to it whenever a native accusation is recorded (old TIR-binding path kept as fallback, r5 tests unchanged), and
  `native_post_final_duty_answered_v1` now reads the recorded answers (no injected silence needed; still `Err` without a record).
- Recovery: `recover_native_post_final_defaults_with_v1` now also scans native accusation rows: `PartyDefault` → refund + slash
  (`PALW_NATIVE_POST_FINAL_DEFAULT_SLASH_V1` still `None` → production does nothing); `NoSlashHold` → `reopen_unsupplied_turn_v1`
  opens turn+1 clocks at this block if they close before H; otherwise the fee stays held and is released at H without slash.
- Cleanup: `after_held_fee_left_v1` (hold fold) deletes the duty record when the fee leaves (release / refund / conviction).
- Dispatch: `palw_flat_execution_fold_v11::apply` arms for 47/48 (subject to its existing `action >= 25` native_final gate; refusals
  are dropped objects like every action there).

## Design decisions / open (honest)
1. **New action bytes 47/48 under `TAG_FUNDED_EXECUTION_V11`** and **aux-144 prefix 0x02** — new IDs (no existing one changed).
   Central collision check needed (none found on base or other g14p branches' diffs).
2. The native clocks reuse `CourtDutyClockV1` as a struct but are NOT staged-court rows: `acquisition = Key::Claim(claim)`,
   `profile_id = native_post_final_duty_profile_id_v1(family)`, `allocation_id = job`, `source_id = demand_id = accusation`.
   `CourtDutyClockV1::check` (TIR-specific) is never applied to them.
3. "Supplied opportunity" for native duties is a per-block capacity fact (room for one packet of the pinned profile after the block's
   unreserved court spend), not a reservation in the TIR service book (whose `check_context` forbids non-TIR / Final claims).
   Reviewers may want real reservations; that needs a native service book (design).
4. An answer is recorded by digest only; its *content* is not judged (a junk answer avoids the silence default; a wrong Final is
   still convicted by the existing atomic public filing). What material the actor owes post-Final is still undefined per family
   (rfc08-hold open 1).
5. Accusation spam cost = carrier fee only (no accusation fee/bond — a money amount, user decision). One open accusation per job.
6. Recovery = re-opened response turns (bounded by H), not re-supply of a past slot.
7. Not compiled: types/paths checked by reading only (`court_cost_spent` fields, `turn_deadline_daa`, `write_kernel_row_encoded_v1`).
