# Retained-original parameter authentication adapter

Parent `0ce909cd9`. Independent of the still Proposed ADR-0199 choice. This is a read-only predicate, not material insertion or full original admission.

`SharedTirContextV1::check_parameter_opening` requires the requested scope and exact current retained context row. It reconstructs and validates that context's actual original/service/source binding, resolves the registered class by the original header, decodes its canonical program through the retained native program decoder, and checks the borrowed opening against that program's canonical inventory and the original's artifact root. Neither root nor program bytes are an input from the submitter. A constructed context with different fields cannot substitute for the retained row. All returned results are ordinary local checks, not serializable credentials or custody/payment/default permission.

The existing inventory constructor calls param-instance analysis twice. A new checked request inventory derives the retained ParamIndex array, both outer instance vectors, reader BTreeSet arrays/nodes and global/per-layer vectors from the actual program's block readers and scheduled layer references. It uses the existing pinned typed BTree allocation envelope and growing-Vec convention. An index ticket is held across construction/check/destruction; the existing native program owner separately retains its decode/analysis ticket. These are conservative allocation requests, not physical RSS, measured CPU, transport capacity or fee calibration. The unit comparison covers retained index ownership, not a physical allocator trace of every scratch allocation. Source reconstruction, repeated program/rules/source validation, request-planning CPU, invalid ingress and all broader resource terms remain caller-admitted unfinished work.

Tests extend the existing public-original GQA history fixture: a genuine parameter opening succeeds; wrong scope, altered payload, non-retained context, missing registered program and corrupted canonical program refuse; the original state root is unchanged. The existing small inventory test additionally compares the request envelope with retained index ownership. Registration/payment and service-book fixture assumptions remain synthetic/verified-half. No funded UTXO admission or actual-node T05 is established.

No peer decoder, shared material row, wire tag, new actor obligation, input fallback, new composite/media path, price, capacity increase, deadline change, original acceptance, slash/credit or settlement is added. Material availability, retention, fair multiblock transport, all-branch reservation/funding, end effects, recovery and real-model door remain incomplete. No pre integration/push, arming or deployment.
