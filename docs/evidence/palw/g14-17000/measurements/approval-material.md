## Decision 1: retain 75/41 only with a corrected claim-draw cap

The earlier ambiguity about `f` is resolved by `palw_security_certification_v1.rs`: `PALW_CERT_PREMISE_ADVERSARY_PERMILLE_V1 = 250` means **at most 25% adversarial verifier stake**. The code names **m = drawn positions, k = positive positions required**. Panel=1 is the liable Panel seat count; it does not replace the separate certification draw of 75 positions. These draws are stake-weighted with replacement; one operator can occupy several positions.

The VAL report says the network cap of 4,096 counts positions. **The implementation instead counts claim draw attempts.** In the reviewed source, `palw_security_certification_fold_v1.rs` increments `network.draws` by **1** at both the chain/native draw (line 806) and the kernel draw (line 921), each of which subsequently draws `policy.m` positions. The guards compare that counter directly with `draws_per_epoch`. Thus dividing 4,096 by 75 does not describe the implemented cap. This is present in both the old measurement source and the latest source reviewed here.

Under independent stake-weighted sampling with adversarial mass f=0.25, false certification is `P(Bin(m,f) >= k)`. Conditional honest certification uses responding honest stake mass `(1-f)*a`; a mean response rate by operator count is insufficient when weights and repeated positions differ. The table uses 365 epochs, **not an unconditional wall-clock year bound**. The reference epoch is 720 DAA; the historical 184 s/DAA observation is not a bound on future epoch speed.

## Decision 2: inclusion delay 4 DAA remains unsupported as a default-liability bound

VAL derives 3 DAA as `ceil(34,000 / (125,000 - 111,949))`, then adds one queued packet. This is a fluid-byte calculation. An atomic 34,000-byte carrier does not fit into **any** block whose residual capacity is 13,051 bytes; unused space cannot accumulate across blocks. Actual fragmentation or enforceable reserved priority could remove that counterexample, but the arithmetic alone does not demonstrate either. Two packets per original also does not bound total backlog from other accepted originals.

**Judgment:** retain 4 only as an explicitly provisional scenario; do not use it as an established inclusion premise that attributes fault. Measure legal carrier sizes including envelope/signatures, admission/reservation, competing traffic, every accepted duty deadline, and reorg behavior. Keep missing supply or missing delivery premise undecided/no-slash according to the existing implementation. M-X3 and M-CAP remain NOT_MET.
