# Material family dependencies and selected runtime operands

## Scope

This isolated implementation joins actual numerical geometry, every root-input relation and real all-role SourceGraph Finish dependencies. Parameter/prompt supplies remain typed unresolved coordinates. Its all-cover material audit remains distinct from runtime: terminal replay checks only the selected root's conservative potential operand relation, then uses the existing current signed root/ancestor/native finalizer. It does not yet derive the exact minimal selected-path readset. All-cover checking retains its original linear input walk; named roots use the opaque native cover's sorted index.

Known Constraint automaton forms now have allocation-free native codec preflight and reserved parsed/canonical-writer scratch before existing typed decoding/normal-form checks. Known version11 Prefix has its existing allocation-free fixed-tail shape check; unknown tails remain Resource. Structural graph support does not activate either native admission path. Old source graph/node IDs and existing caps are retained.

Constraint has a checked compact D×V×(V+1) potential token domain and a distinct actual end-position Stop. Potential supplies stay separate from runtime bytes: new duty-bound borrowed-material entries preserve existing signatures/native replay and permit only needed renderings, including EOG-only Stop. Prefix resolves actual native context/StepSpace/template boundary ordinals and connects them to real supplier finishes, then delegates authenticated bodies to existing canonical replay.

Tokenizer derives actual all-V targets from current immutable semantics, full retained table/raw/EOF and actual native Generated proof provenance. Generated stores actual authenticated raw hash/length and the producing Court's signed key-work bound; family requires the same actual current immutable bound. It does not equate proof count with V or require a JSON-valid verdict. Same-bound authenticated invalid/overrun data can remain local fault material.

## Review repairs and authority boundaries

Review found and corrected both artifact-only Tokenizer provenance and the numerical allroots/runtime mix-up. Constraint retains full-material convenience while also exposing selected borrowed-material duty entries. Source/parser/proof/signature/finalizer transient ownership still requires independent native admission; these family metadata leases do not admit every builder allocation or establish physical cost/throughput.

Current constructors are postclaim components, checking actual current retained frames. They do not replace the future pre-reservation native PreparedFrame authority. Caller-decoded frame/profile IDs are not native authority. No absent semantic supply namespace is fabricated as a SourceGraph Unit/Finish, and no result installs funded admission, fees, locks, default or financial discharge. Prefix generation selection/stop and exhaustive all-family reservability remain separate incomplete work.
