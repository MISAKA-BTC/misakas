# RFC-0006 held-GDN borrowed predecessor witness owner — 2026-10-25

## Production boundary

The retained held-transition route carried the accused witness's copy ticket through court
and output admission. When native cadence selected a predecessor, it separately cloned selected
recomputed predecessor chunks and built their checkpoint/state Merkle openings without a
predecessor-construction ticket. This continuation admits that named construction boundary.

An additive retained native transition route uses the same site, exact predecessor start,
input assembly and serialized refutation fields as the existing raw builder. Only its witness
provider differs. The exact native predecessor callback returns a typed Result. A Resource from
that callback or from the subsequent witness request/build propagates directly; it cannot become
missing checkpoint material or an honest verdict. The existing raw callback/String compatibility
routes remain available and retain their previous interface.

The actual Base0 retained v4 transition caller uses the additive native route. The predecessor
has already been recomputed by `honest_chunks_v2` and compared with the committed leaf before
the new borrowed request exists. Dynamic semantic replay reasons retain the existing String
side channel, and the final map reuses `base0_gdn_court_error_with_replay_v3`: Resource always
wins over that saved semantic reason. No classification depends on matching error text.

The callback's initial `leaf.clone`, prefix/cache execution, state serialization, and root
hash construction all precede this request. They remain separate input boundaries. This record
does **not** claim that all predecessor work is reserved from its first allocation.

## Request and lifetime

The request borrows actual already-replayed chunks, the native checkpoint hashes and signed
profile. It first acquires the existing native recurrence metadata owner. The native selected
delta traversal is shared with the historical collector, preserving layer/head/block order and
checked offset meanings. The new route compares/counts that traversal without constructing a
selected-index Vec. Unsupported retained layouts refuse explicitly; this new builder currently
quotes the held map, with no unreserved fallback for another layout.

Pre-build review restored the historical `Unadjudicable` refusal at the two shared flat-index
conversions (selected delta and convolution). An offset/local index that cannot fit the native
u32 chunk address is a wire/court representation refusal, not local memory quota. The previous
convolution continuation had inadvertently classified that boundary as Resource; this scope
corrects it. Genuine request-size and allocation-ordinal overflow retain typed Resource. No wire
limit or accepted geometry changes, and no earlier test result is relabeled as testing this
correction.

Persistent roles cover the selected witness Vec's native type slots, actual selected chunk
byte clones, native block/top sibling path destinations, checkpoint-opening siblings and leaf
heap. Typed push-growth envelopes include old/new overlap and minimum Vec capacity. Clone
destinations use actual source lengths. Actual returned capacities are checked while both
admissions remain live; excess or unsupported coverage is Resource, before publishing a result.

Workspace covers the checkpoint tree `N+ceil(N/2)` Hash64 peak and the native Writer, or the
state-path construction roles: full state leaf hashes, held top array S, one slice's block hashes
B, sequential block/top fold levels and temporary top path. It also covers the real additional
temporary layout derived by existing map helpers while the request's native layout remains
borrowed. Full state leaf collection uses a conservative typed push envelope. These are explicit
source allocation roles, not a serialized-byte multiplier. Per-selected-chunk path construction
is sequential; its workspace is not multiplied by the number of selected witnesses. Previous
copied paths/chunks are in the persistent request.

The state chunk Writer request uses its real sequence: map hash, slice, block, length prefix,
then a bulk actual chunk. Its 256-byte initial allocation and old/new growth are accounted for,
including chunks larger than that initial capacity. The combined role sum is conservative,
not a minimal allocation, physical allocator overhead, RSS or model-cost measurement.

Requesting and building are separate stages. `.build_v3()` admits persistent and workspace
roles before opening a tree or copying selected chunks. The returned witness is declared before
its owner. Native transition construction retains that owner while it consumes the witness,
and Base0 transfers it alongside the independent accused-copy owner. The existing value-before-
owner carrier keeps both through the actual native court and signed-output admission. The
concrete node output has its own ticket before these input owners retire. The public explicit
parts transfer itself does not guarantee a consumer's lifetime obligation; this actual caller
fulfills it without an await or raw unguarded return.
