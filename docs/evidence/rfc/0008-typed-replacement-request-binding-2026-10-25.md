## Missing consumer invariant

`kernel_material_replacement_v4` validates the original context request against the intent, accepted financial/recovery nonce, original producer key, exact current previous consent/sequence, fresh actors' actual collateral and complete material replay. Its opaque `PalwKernelMaterialReplacementOwnedV4` previously retained the verified manifest but did not expose the authenticated original request ID. `DurableMonetaryMaterialProviderV1::prepare_replacement_kernel_v4` receives a separate restart context and checked only its root/manifest against that grant. A caller could therefore pair one actual native replacement grant with a different context request naming the same material manifest, publish replacement bytes, and save metadata that later current-native restore would correctly refuse.

The core owner now stores one private fixed `Hash64` copied from the authenticated original context at its sole constructor and exposes a borrowed-input-independent `context_request()` getter. The public provider consumer requires exact equality before capsule identity hashing, candidate construction or either disk publication. The shipping native replacement endpoint already passes this owner into that method, so it obtains the same check without another caller convention. No wire layout, enum discriminant, policy, Params, consensus identity, signature preimage or API trait signature changes. This guard binds the original request identifier; full context-body/signature/nonce authentication remains mandatory in the existing current-native restore path.

## Actual native fixture and boundary

The new public filter is `rfc08_typed_replacement_exact_request_native_acceptance_and_historical_cold_read`. It uses the private role driver with `MISAKA_TYPED_REPLACEMENT_CHILD_V4=1`; the original initial-publication filter keeps its original scope. The writer first completes real job/seal, complete SDK TypedKernelV4 material, native ingress, both initial provider preparations, signed funded acceptance, claim admission and initial cold current-positive reads.

An additional acquisition-only process then opens the actual old provider's context archive with its retained metadata owner and calls the real own-node replacement API. It requests sequence 1 with the exact accepted previous consent, original request and a bounded explicit deadline, using fresh providers 4 and 5. The wrong-request control preserves the exact manifest and must refuse before either new provider file changes. Both new stores must durably prepare before any ordinary 241 or recovery 242 signature. The checked native generation API must classify this not-yet-accepted generation as `Denied`, not resource/unavailable, and exact provider reads must refuse it.

The unarmed writer subsequently carries the actual signed bounded replacement through the mempool/block/native fold. It requires sequence 1 and the exact expected bounded consent, previous consent and immutable deadline; a higher sequence alone cannot establish acceptance. A final acquisition process cold-opens all four provider stores and obtains exact current-native answers under both the old historical consent and the new current consent. The current-monetary-consent API must return false for the old consent after replacement, while historical generation authority must still authorize its retained bytes. That distinction prevents deleting still-obligated old material merely because it is no longer current.

Only ordinary request/context metadata and signed carriers cross process boundaries; opaque verified grants are reconstructed by real own-native APIs. Each role releases every DB strong owner and exits before the next opens it. Native writers remain unarmed for resource admission; reader processes open/warm the existing node first, then declare acquisition-only metadata budgets and submit no native block/object. The fixture does not weaken the unsupported hard-DB-quota refusal or retained-state extraction guard, and it claims no whole-node allocator/physical-database bound. It retains the explicit private commitment-only court prerequisite, tiny artifact/OPV eligibility seams, skip-PoW and simulated clock of the initial fixture.
