# RFC-0006 typed held-GDN court Resource — 2026-10-25

## Actual production boundary

The actual held terminal called the native transition/convolution court but converted its
`PalwGdnCourtErrorV2::Resource` into a String, then into the retained filer's generic Operation.
The result already withheld rather than convicting or advancing, but the local capacity retry
classification was lost. The Base0 retained evidence/demand helpers also formatted native court
errors inside their borrowed-leg implementations. Retaining leg admission alone did not repair
these subsequent boundaries.

The shared typed court mapper now preserves native Resource exactly. Retained native demand,
checkpoint-witness and transition/convolution evidence calls use that mapper, while legacy raw
String interfaces format errors only at their compatibility boundary. A predecessor recompute
callback's recorded String refusal can explain an Evidence failure; it cannot override a native
Resource. No text matching determines the error class.

The actual node terminal maps only exact native `Evidence(NoFaultFound)` to an honest candidate
advance. Success permits the existing terminal-checked accusation; Resource stays Resource, and
other Evidence errors remain refusals. Existing claims, binding/authentication, native court
checks and signed output handoff retain their prior requirements. No default accusation is
created from missing work or local capacity, and no new evidence acceptance rule is introduced.

## Explicit remaining work

This patch preserves typed native court admission errors; it does not reserve the refutation's
nested row/tile/path construction, replay/prefix state construction, authentication scratch,
PerDecodeCall served-chunk/frontier reconstruction or generic host case-book/history maps.
Recompute backend errors are still an existing String refusal boundary and are not classified
by their text. The earlier capture/leg/answer/output owners cover only their named allocations.

Formal K3 specification/manifest/weights/signed inputs remain uncreated, and the fifteen campaign
gates remain UNKNOWN. Small deterministic fixtures are not all-model cost or an accepted
multi-process court campaign. Public activation stays None, ordinary selected-source/V6
bootstrap refusal and model tiers remain, and selected-verifier claim authentication is unchanged.
