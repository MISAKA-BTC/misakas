## Production connections

- **Court EDF:** production `CourtOutboxV1::try_take_priority` reserves two compact typed arrays before
  ordering or draining. Grouping by claim computes the earliest deadline among moves actually queued;
  explicit original indices preserve every stable tie, including all undated entries. In-place cycle
  permutation moves the existing payload buffers without cloning them. Allocation/refusal occurs before
  any queue mutation. The former allocating HashMap/stable-sort implementation remains only as a test
  parity reference. The carrier retries after local resource refusal; it does not treat refusal as chain
  invalidity. At the beginning of a new flush, after the prior carrier future/batch is gone, canceled
  batch tickets are reclaimed before requesting more scratch, avoiding a quota stall.
- **Private checker reorg:** a valid saved receipt with a currently different assignment, context or
  seed is retained and polled again instead of permanently stopping the worker. Fixed enrollment,
  round or actor mismatch remains a hard refusal. The signature is checked before the retryable native
  binding check. No receipt, transaction or funding is rebound to the new snapshot. See the
  [checker record](0007-checker-saved-receipt-native-retry-2026-10-24.md).
- **Recovery carrier pre-relay authority:** both new and restored transactions require current native
  UTXO/payer/change/fee/maturity/bond checks and a positive own-fold rehearsal immediately before relay.
  Import epoch, sink and DAA are checked around the synchronous observation. This check runs after the
  async mempool lookup; an identical already-pooled spend continues waiting normally. Failure retains
  the immutable WAL. See the [recovery follow-up](../../design/palw/execution/rfc08-bounded-release-recovery-v2-2026-10-15.md).
- **Historical-header consumer:** the actual acceptance judge checks the native counter partition,
  exact integer widths, complete totals, capped named lists, identities, duplicates and maximum sizes.
  Both roles must name the fixed native 1,599,931-byte carriage cap; a cross-language control rejects
  drift in the source constants/expressions. Empty eligible history is unexercised/BLOCKED. The separate
  campaign now pins its process-group helper and checks actual local-import closure. See the
  [header and source-pin record](0006-0012-historical-header-census-consumer-2026-10-24.md).
