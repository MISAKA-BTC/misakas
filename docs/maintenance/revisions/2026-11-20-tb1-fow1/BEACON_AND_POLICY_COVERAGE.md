# 全RFC・ADRと旧beacon記述の適用台帳

2026-11-20（Asia/Tokyo）。**ADOPTED_DESIGN_NOT_ACTIVATED**。

これは原文の過去状態を改ざんする置換表ではなく、新規PALW採掘で適用する規範を明示する台帳である。現行20 RFC-v2・50 ADR-v2にはそれぞれ担当別の適用節を追記し、59/60・227/228は関連本文も改訂した。旧原文・埋込履歴・測定結果は保全し、新規受付のfallbackにはしない。

正本: [RFC61 TB1](../../../rfc/0061-palw-internal-threshold-beacon.md) / [RFC62 FOW1](../../../rfc/0062-palw-function-output-and-work-admissibility.md) / [優先順位と移行](../../../governance/palw-tb1-fow1-transition.md)。

## 網羅範囲

- 元の番号付き文書 **355件**を全件収録。新規4件を加えた **359件**を以下に示す。
- 元文書 **536件**にある検索該当 **5,252箇所**を、元path・SHA・行・節・原文付きでJSONへ収録。
- 無関係なローカル試験PRNG、鍵生成、EVMの乱数をTB1に書き換えない。採掘の未来乱数に転用する経路は認めない。
- 検索該当の全分類は、全行の暗号学的正しさやLLM費用定理を証明するものではない。現在の適用規範と履歴の境界を確認するための記録である。

詳細: [機械可読の全記述台帳](beacon-and-policy-coverage.json)、[変更前棚卸](randomness-before.json)、[用途別consumer契約](../../../design/palw/consensus/tb1-beacon-consumers.json)。

## 用途別の結論

| 用途 | 新規profileで適用する規則 |
| --- | --- |
| 実行challenge | TB1-EXEC。全候補・target等を最初の正直share前に安定固定。 |
| Panel選出 | 別秘密のTB1-PANEL。署名済み元claimとpoolを後段で別に固定。 |
| Court positive | 正規PANELと元claim・担当者・義務から派生。追加の未来抽選ではない。 |
| negative・資料・終端 | 新beacon待ちなし。元予約と原期限を維持。 |
| FOW1受付順 | 唯一のTicketとslot ID。別ADMISSION抽選を重ねない。 |
| 別control受付順位 | 明示採用する場合だけ独立TB1-ADMISSION。未確定経路は無効。 |
| EXEC権割当 | 独立TB1-SCHEDULE。適格credit集合を公開前に固定。 |
| 次holder roster | 前epoch保持者の独立TB1-ROLE。初回bootstrapを別に明示。 |
| 生成sampling | 登録済み規則でEXEC/sから決定論的派生。 |
| 採掘Ticket | 四Rootとsへ一意束縛。SWC1の第三R_ticket、旧複数drawを廃止。 |
