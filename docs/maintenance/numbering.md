# 文書番号と責務

RFC・ADRはそれぞれ0001〜0020の20本です。同じ番号は同じ分野を担当し、RFCは実装設計、ADRは判断理由を扱います。次の番号は必要性を確認した上で0021から使用し、既存分野の更新を優先します。

旧本文をarchive・履歴・別版として保存しません。旧参照は[RFC対応表](../rfc/MAPPING.md)と[ADR対応表](../adr/MAPPING.md)で解決します。旧番号を含むwire tag、署名domain、enum、テスト名、DB schemaは文書改番と別です。

## 旧番号の重複

旧RFC0042、旧ADR0026・0173・0193・0210は完全な旧ファイル名から解決します。数字だけで一括置換しません。現行体系に重複番号はありません。
