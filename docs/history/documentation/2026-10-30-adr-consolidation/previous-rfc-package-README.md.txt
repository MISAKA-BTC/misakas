# MISAKA RFC整理パッケージ — 現行15本

このパッケージは`misakas-pre(5).zip`の文書overlayです。runtimeコード・合意設定は変更しません。新しい主題別RFCは15本で、旧41本は既存パス・同じbytesのまま参照資料として含めています。

同じsnapshotのcheckoutへ`docs/`を重ねて反映します。別branchの更新がある場合は差分mergeしてください。[反映方法と未解決事項](docs/rfc-v2/MIGRATION.md)に編集範囲と検査方法があります。

統合本文・旧原文・ADR・主要なpolicy/spec/historyを同梱しています。旧資料からリンクされる全ての実行ログ・runtimeコードはこの小型パッケージに重複収録せず、元のrepositoryを参照します。
