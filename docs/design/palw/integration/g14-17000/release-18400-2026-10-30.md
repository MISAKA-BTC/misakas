# G14 DAA 18,400 への移動台帳

2026-10-30。ユーザーが、前 G14 は未公開であり DAA 18,400 で有効化したいと明示指定した。これは設定変更と実装継続の記録であり、最新候補の検証成功や公開配備の宣言ではない。

## 設定した範囲

既存採択済み `PALW_T12_G14_17000_FENCES_V1` の予定高を 18,400 に移した。歴史的な定数名を残し、`PALW_T12_G14_18400_DAA_V1` を新しい高の定義とした。int-13 の 15,500 と genesis は変更しない。全機能リストの `PALW_T12_FULL_ACTIVATION_DAA` は `None` のまま。

この隔離候補は origin/main の既存 G14 実装と高の変更だけを含む。未完成10領域の作業差分は含めない。

新しい [生成器](../../../../../scripts/release/gen_t12_18400_records.py) と [18400 records](../../../../../consensus/core/src/palw_t12_18400_records_v1.rs) が新高を束縛する。旧 17400 generator・records・suite JSON・logs は変更しない。過去 suite の source/digest は当時の実行を示し、新 18,400 候補の PASS を示さない。既存 waiver の種類・許可範囲・数値を拡張しない。

## 追加機能の状態

| 項目 | 今回の予定高設定で有効化したか | 残る条件 |
| --- | --- | --- |
| 既存 G14 リスト | 18,400 を設定 | 最新同一候補のビルド、対象試験、起動・境界確認、identity 再計算 |
| RFC-0042 四 family supplier / 材料・費用 | いいえ。隔離候補へ専用 fence/実装を追加しない | finance/material/settlement 依存と、実ノードでの全 branch・restore・adjudication 検証 |
| RFC-0039・settlement-once・income 系 | 一括有効化していない | 各 consumer の支払・返金・reorg/restore と各 validator が要求する記録 |
| RFC-0023 claim-local stage 2 | いいえ | material retention / transition drill。現行 guard は実高の設定を拒否 |
| native39 execution/mining → EVM 決済 | いいえ | exact policy の measured record、実ノードの認証・満期・再起動・pruned handoff 検証。独立 D を含む混合決済も残件 |
| 回答会計 / winning carrier | 新規には有効化していない | 専用 fence の依存・arming 要件と同一候補の実経路検証 |
| Genesis Bond ゼロ起動 | 新しい起動 policy は有効化していない | native/worker/collector を含む lineage・security/economic acceptance と guard の充足 |
| RFC-0040 / RFC-0037 接続 | 新しい公開有効化を宣言しない | 認証済み源泉・依存、行 stream・P2P の同一候補検証。既存 G14 高の変更だけでは全 RFC 完成を示さない |

画像・動画・モデル改善は初期 mainnet 延期のまま。計算の暗号学的証明やモデル単位の審査は導入しない。

## 現在の確認と残作業

生成器の再現性と実 deploy kit の placeholder 拒否は [2 試験が成功](../../../../evidence/palw/g14-18400-2026-10-30/README.md)。入力ファイル hash と raw log を保存した。Rust の設定・境界・起動試験は root の統一ビルドで実行する。新しい PASS と source manifest は別の実行証拠として追加し、過去証拠を上書きしない。

対象 integration tests は `palw_t12_g14_17000_arming`、`palw_t12_17400_activation_readiness`、`t12_fleet_identity_247ade1f9`、`t12_deploy_kit_constants`、`palw_t12_full_activation_16000`。歴史的な test 名を維持するが、現行予定高の検査は 18,400 を用いる。

`fleet.env.example` の `EXPECT_FP` は未設定であり、`require_release` が配備を拒否する。ビルド後の `t12_repin_values` / `t12-repin.sh` harvest と release binary の identity probe で実値を求める。新しい高だけから fingerprint を推測しない。公開配備は未実行。
