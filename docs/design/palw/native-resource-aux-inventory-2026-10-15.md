# Native resource scanner: kernel-route aux row inventory (tables 42–106, 112)

_2026-10-15. Generated by `scripts/drills/rfc06_native_aux_spec.py`; the same module drives the scanner arms (`gen_rfc06_native_wire.py`) and the type roots (`gen_rfc06_native_inventory.py`). Regenerate, never hand-edit._

Every row the scanner meets in these tables is dispatched by its full key (`k`) and, where two layouts share one key shape, by its fixed row length (`n`). A key shape no fold writes fails closed ("unallocated … namespace"); rows exist only past their owning fence, so that refusal can only fire above it. Write sites are every `write_kernel_row(…, Some(…))` found by `git grep` (tables written through a local are traced to their constant).

## Conventions

- `D` = `[u8; 64]` (`Digest`), `B` = `PalwBondKeyV2` (68 Borsh bytes: a `Hash64` transaction id and a `u32` index), `H` = `Hash64`.
- `raw:N`: a byte string stored verbatim (not Borsh-framed, never decoded by restore or ledger projection). The scanner checks the declared bound N, then accounts the bytes as one more transient copy (the outer loop already counts the stored row and its copy).
- `mirror:T`: a fold-private struct; the generator expands its declared fields into a Borsh-identical nested tuple, so the accounting is the struct's own structural walk.
- `any:A|B`: one key shape, two family layouts (each family writes only its own ids). The bounded row is buffered, every layout is tried, the largest accepted shape is accounted; none accepting fails closed. **Marked ambiguous.**

## Coverage

- 375 value-writing sites into these tables, 194 namespaces; every site is claimed by exactly one namespace and every namespace by at least one site (the generator run fails otherwise).
- Ambiguous key shapes (handled conservatively, see `any:`): table 92 `(29, job, 23)` (Text29 rooted carriage record vs Stage28 bare record) and table 106 `(29, 4, id)` (discovery replacement vs collected credit; told apart by fixed length).
- Table 105 `(14, job, ordinal)` carries a 64-byte v11 demand id or a 65-byte `(16, source16 pending)` pair; dispatched on the exact row length.
- Registry completeness is enforced by `palw_native_resource_v1::aux_registry_tests` (source-discovered tables must reach an explicit arm).
