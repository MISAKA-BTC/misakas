Every parameter below exists in source only as a **named field of a fenced policy** (or a named RFC parameter). No preset
carries a value, every fence is `None` on shipped networks, and each fence's validator refuses real activation. Probe
values (`unapproved_probe_*`, private-profile mechanics values) are test inputs, not proposals. A recommendation appears
only where an existing record derives one; "measure" means the value cannot be chosen before the named measurement.

only; **recommended** = derivable from records, awaiting the user; **open** = no defensible value yet.

## 3. RFC08 economics (R8-ECON) — minimum-price contract `palw_minimum_price_v1`

`PalwMinimumPricePolicyV1 {capital_rate_ppm, capital_rate_period_daa, p_collect_lower_ppm, class_cost_upper[(class, C_upper)], maximum_contracts, maximum_contract_daa, cost_report_root}`.

- `C_upper = compute + recomputation + material/acquisition + carriers/filing + capital_rate × distinct_capital_time_area + other_outcome_costs`
- `required_M = ⌈C_upper / p_collect_lower⌉`; refuse if `p_collect_lower = 0` (UNKNOWN) or the class is unmeasured.
- Recommendation: **measure** `C_upper` per class from a reviewed cost report; `capital_rate` from the operator's actual cost
  of capital (no record supplies one); `p_collect_lower` from the joint native-Final × release collection analysis (ECON §14).
  No value is recommended before those measurements.
- **Settlement enforcement (round 3, source only):** the floor `floor(claim) = funded_minimum_sompi` of a signed contract whose
  worker's claim holds the job is injected into the kernel ledger (`consumer_minimum_payouts_v1`, never a row); at Final
  `paid = min(escrow.amount, poster collateral, consumer cap)`, and `paid < floor ⇒` neutral: `paid := 0`, the escrow is
  released whole to the poster (`ReleaseJobEscrow`). No new parameter. **USER DECISION REQUIRED:** whether a neutral outcome
  (worker paid nothing because the escrow can no longer fund the contracted minimum) is the intended contract rule, or whether
  the shortfall should instead be charged to the poster's bond.
- **Retirement sweep (round 3):** a minimum-price row retires when `now > accept_by_daa` unsigned (stale consent),
  `now > retention_until_daa` (expired), `now > accept_by_daa` with no worker claim on the job (unused), or once the job's escrow
  is gone (settled); a horizon-extension row when unapplied and `now > consent_by_daa`, or applied and
  `now > new_liability_until_daa`. Uses only existing fields (`maximum_contracts`, `maximum_open_extensions` capacities are freed).
