# BFT validator — 旧資料の案内

新しい採用設計はBFT validatorを使用しません。[旧ADR-0180](../rfc/0001-principles-and-governance.md) / [RFC-0012](../rfc/0015-dag-blocks-and-settlement.md)。

旧DNS-finality validator runbookと[旧導入手順](https://github.com/MISAKA-BTC/misakas/blob/f839ef0dc0307b58ed6cc280e631b1e1d34f733c/docs/history/documentation/2026-10-17/getting-started/validator.md)を保持しています。これらは新規導入の推奨ではありません。

設計退役と稼働network上の退役は別です。移行・有効化を確認せず既存nodeや債務を停止・解除する指示ではありません。claimごとの抽選検証者は固定BFT集合と別です。[状態](../STATUS.md)。
