# MISAKA PALW PoW 詳細設計 v0.1 — 不採用理由

Status: **Withdrawn / 不採用。**

恒久 hash floor の横に float worker の PALW certificate と追加報酬を置く旧導入案は継続しない。hash lane が有用計算を迂回する誘因と混合 difficulty の負担を生み、float class は異種 CPU の厳密一致と客観的裁定を保証できないため。[ADR-0038](adr/0038-palw-is-the-consensus-work.md)・[ADR-0039](adr/0039-palw-only-block-production.md) と [ADR-0053](adr/0053-palw-one-execution-family.md) の方針へ置き換えた。
