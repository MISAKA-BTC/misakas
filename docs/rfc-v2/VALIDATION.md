## 判定に含めないもの

Rust/Cargoのbuild、実ノード、P2P、court、報酬、genesis、有効化を実行検証していない。文書編集だけでそれらの完了を宣言しない。

原条文内の既存リンク・既存anchorは旧文書へ向け直しているが、全ての歴史リンクが現在も有効だとは保証していない。旧資料から参照する全実行ログとruntimeコードは小型overlayに含めず、元repositoryを使う。新規リンク370件の検査と、過去資料の全参照監査は別である。

既存のCI／索引生成器の動作は変更していない。v2の15本文を自動列挙したい場合は`registry.json`を参照する接続が別途必要である。旧番号を追う用途では旧索引を使い続ける。

## 再実行

```sh
python3 docs/rfc-v2/check_integrity.py
```

この検査は原文hash、移行先、全行被覆、収録断片hash、新規リンクを確認する。合意仕様の形式証明や、未解決の政策矛盾の解消を代行するものではない。
