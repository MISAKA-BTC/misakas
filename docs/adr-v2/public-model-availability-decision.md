# ADR: 公開モデル取得可能性を成功 Final の条件にする

状態: 2026-11-10 ユーザー方針の記録。詳細設計・レビュー・有効化は未了。

## 決定

[原則 §9](../PRINCIPLES.md#9-モデルの二階層と公開取得可能性--2026-11-10-ユーザー決定) に従い、モデルの公開取得可能性を成功 Final の必要条件とする。Hugging Face を原則とし、使用できないときは共通手続きで同等の別サービスを指定する。公開取得検査と claim ごとの認証を併用し、二階層の係数は変更しない。

## 結果

外部サービス、検査者と通信環境への依存が生じ、停止や到達不能時には成功 Final が遅延または不成立になる。公開検査は全員の取得成功を保証せず、計算の正しさを示さない。[RFC](../rfc-v2/public-model-availability.md) の未決事項、独立レビュー、実装・検証と変更管理を完了してから有効化する。
