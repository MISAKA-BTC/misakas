# RFC — 旧番号の互換入口・履歴

現行の閲覧・更新先は **[RFC 15本](../rfc-v2/README.md)** です。旧文書との[完全対応表](../rfc-v2/MAPPING.md)から統合先を探せます。

旧番号の本文・既存パスは、コード・仕様・証拠からの参照と判断履歴のために保持します。新しい参照には `RFC-v2-xxxx` を使い、旧番号の意味を変更しません。
