# MISAKA Audit-Fee v0.2 — 不採用理由

Status: **Withdrawn / 不採用。**

旧 Token Program の別通貨 emission に verifier の再実行報酬を統合する案は採用しない。前提の compute-token 台帳と VLT compute overlay が撤回・削除され、専用の emission と activation を追加する理由がなくなったため。[Token Program の不採用理由](misaka-compute-token-program-design-v0.1.md) と [ADR-0134](adr/0134-the-compute-overlays-committee-beacon-retires-at-a-height-and-its-machinery-goes.md) を参照する。
