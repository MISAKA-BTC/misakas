# Source C candidate: lifetime audit

Source-only constructor addition; no old call site, activation, schema, price or full graph touched. Patch not built/applied.

1. Borrowed scanner runs against current registered.program after check_program length/hash. It returns opaque shape and no decoded program.
2. Native quote sums existing A codec/analysis quote, B StepSpace vectors, one raw canonical-program Vec clone, two layout clones (binding.class.layout + live verified.space.layout), THREE header-native-heaps conservatively bounding (binding.job_context + PalwDecodeView.job_context + returned Source.header), RUN u64 output Vec and native owner frame.
3. Source::new calls resolve_registered_layout, whose resolve_owned_class invokes verify_tir_binding and drops its verified temporary at `...?;` BEFORE returning binding. Source then independently invokes verify_tir_binding and retains that verified space until returning. TWO total decode/validate/StepSpace passes, maximum ONE live verified space at a time. Thus one A+B quote covers the peak. Binding raw program/layout remains live through both; its copies are separately counted.
4. from_tir_header only checks registered bytes/header roots and clones job_context into decode view; it does not decode another StepSpace. The THIRD dynamic job context clone must not be omitted.
5. maximum_window_lanes_v1 runs RUN times over retained occurrence/commit/fixed/hist Vecs, uses scalar/u128/iterator stack scratch and no Vec/collect. Its results collect into RUN-element Vec. cone_runs_bound similarly only iterates existing Vecs. Verified space + view + binding coexist with that vector; retained Source.header is cloned at return.
6. Hash writers: class.layout_digest -> Borsh to_vec(layout), Source sourceID -> Borsh to_vec(header), context_hash -> CanonicalWriter(job_context). Same context scalar field order/width as Borsh, including u32 network byte prefix. Borsh initial capacity1024; CanonicalWriter initial512. Calls are sequential, so max(logical layout/header/context bytes,1024)*2 covers one live growth-capacity writer. Program canonical reencoding writer is in A separately and could be conservatively co-reserved without double-authority meaning.
7. The complete conservative construction reservation stays attached to NativeRetained<Source> for entire returned lifetime, even after binding/verified/view drop. It does NOT claim that final Source retains all those bytes or measure physical RSS; C deliberately avoids a split/release optimization until scope is verified.
8. Off-mode `reserve_native_requests_v1` can return None under existing framework. The constructor owns an unchanged Source but never returns paid admission or claims an enabled native quota where disabled. No old callers silently switch to this constructor.
